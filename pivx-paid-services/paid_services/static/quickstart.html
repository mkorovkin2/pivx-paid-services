PIVXServicesUsageQuickstart
Testnet6 integration guide

Your first testnet service

Use Python 3.11+ and dedicated local Core testnet6 sender/receiver nodes. Obtain free faucet tPIV and shield the payer balance first. Set PIVX_SERVICES_URL to the running service. The repository README and TESTNET.md explain setup. The on-chain flow still requires live verification; upstream Agent Kit currently uses mainnet.

  1. Create an invoice

    umask 077
python3 -m paid_services invoice --service analytics --request-id first-purchase > invoice.json

    Keep the invoice JSON and private session file. Reuse the request ID after an interrupted response.

  2. Pay with testnet Core

    python3 -m paid_services.testnet_wallet --config wallet-config.toml pay --invoice-file invoice.json

    The separate payer checks testnet6 genesis, receiver allowlist, amount limit and exact memo. Fees are additional. A lost send response stops for operator inspection. Simulation invoices are refused.

  3. Collect the result

    python3 -m paid_services result --invoice-id INVOICE_ID_FROM_FILE --service analytics --request-id first-result

    The client waits for verification and returns JSON. Retries with the same result request ID return the stored response without another charge.

Use MCP

Register the services launcher and the separate testnet Core wallet launcher with absolute paths. No package installation is needed when both sibling project directories are present.

{
  "mcpServers": {
    "pivx-services": {
      "command": "/ABS/PATH/python3",
      "args": ["/ABS/PATH/pivx-services-mcp/run.py", "--session-file", "/PRIVATE/PATH/services-session.json"]
    },
    "pivx-testnet-wallet": {
      "command": "/ABS/PATH/python3",
      "args": ["/ABS/PATH/pivx-services-mcp/wallet.py", "--config", "/PRIVATE/PATH/wallet-config.toml", "serve"]
    }
  }
}

Call list_services → get_quote → create_invoice. Pass the complete returned invoice object to the wallet's pay_testnet_invoice. Poll check_invoice every ten seconds, then use call_service. Give payer RPC credentials only to the wallet process.

Credit and refunds

Partial payments that expire, late payments, and excess payments become credit after three confirmations. A new invoice can apply credit with --use-credit. Check it with python3 -m paid_services account.

Testnet refund requests reserve credit for private operator reconciliation. The service backend does not send funds.

Privacy and recovery

Your session file controls invoices, credit and access. Keep it private and preserve the payer send journal. The public dashboard counts anonymous integrations, not unique wallets.
